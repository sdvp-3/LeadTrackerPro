# LeadTracker Pro

A lightweight lead manager for freelancers and small businesses. Add and organize contact details in your browser without installing dependencies or setting up a server.

## Features

- Add leads with a name, status, email, comment, and date.
- Search saved and favorite leads by name.
- Double-click a saved lead to move it to Favorites.
- Edit or delete a lead from its options menu.
- View saved, favorite, and total lead counts in the dashboard.
- Sort saved and favorite leads alphabetically by name.
- Keep leads in the browser with `localStorage`.

## Getting started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Enter the lead details and select **Save**.

No build step, package installation, or server is required.

## Data storage

Lead data is stored locally in the browser using `localStorage`. It is available only in the same browser and device; it is not synced to an account or backed up to a server. Clearing the browser's site data will remove saved leads.
