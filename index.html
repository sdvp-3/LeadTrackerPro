About LeadTracker Pro

LeadTracker Pro is a web application for managing leads and customer information. It is designed for freelancers and small businesses who want to keep their contacts organized.

What can you do?

  • Add a lead with a name, status, email, comment, and date.
  • Edit or delete saved leads.
  • Move important leads to the favorites section.
  • Search for leads by name.
  • Keep lead information in the browser using localStorage.

Technologies

This project is built with HTML, CSS, and Vanilla JavaScript. It is a work in progress, and more features are coming soon.
